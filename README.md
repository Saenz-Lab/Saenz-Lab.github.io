# Saenz Lab Website

This repository hosts the Saenz Lab website via GitHub Pages: https://saenz-lab.github.io

## Editing content
- General pages live in the repo root (e.g., `research.md`, `join.md`).
- People entries live in `_people/` (Markdown files).
- Publications entries live in `_publications/` (Markdown files).

Changes to `main` are published automatically.
